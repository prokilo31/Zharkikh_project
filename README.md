Название проекта: Сравнительный анализ строительных материалов и конструкций в информационной модели коттеджа с точки зрения энергоэффективности и жизненного цикла
Направление: Исследование и сравнение вариантов материалов и конструкций коттеджа в среде BIM (информационного моделирования) по критериям энергоэффективности и полного жизненного цикла здания.
Статус: В разработке
